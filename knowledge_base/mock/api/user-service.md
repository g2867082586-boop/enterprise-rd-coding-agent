# 星云商城用户服务接口

## POST /api/v1/auth/login

登录请求必须包含 `username`（3 至 64 个字符）和 `password`（8 至 128 个字符），可选字段 `device_id` 用于风控追踪。成功返回访问令牌摘要、用户编号和过期时间；日志和 Agent 输出不得记录明文密码或完整令牌。

失败错误码：`AUTH001` 表示凭据无效；`AUTH002` 表示账号被禁用；`AUTH003` 表示同一账号五分钟内失败次数过多。排查时依次核对字段校验、用户状态、密码哈希版本、限流记录和服务时钟，不允许直接查询或展示密码哈希。

测试入口为 `tests/scenarios/test_login.py`。默认成功用例验证 alice 可以登录；带 `demo_failure` 标记的用例模拟认证服务错误地把有效账号判为 `AUTH001`，只用于失败分析演示。
